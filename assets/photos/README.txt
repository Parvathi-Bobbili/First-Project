Copy your real photos here!

By default, the website looks for these photo names:
  1. photo1.jpg
  2. photo2.jpg
  3. photo3.jpg
  4. photo4.jpg
  5. photo5.jpg
  6. photo6.jpg

(You can also use .jpeg or .png files!)

TO ADD MORE PHOTOS:
1. Copy any photo into this folder (e.g. "trip_with_akka.jpg")
2. Open "js/gallery.js" in your editor
3. Add a line to the PHOTO_COLLECTION list:
   { id: 7, src: 'assets/photos/trip_with_akka.jpg', caption: 'Sweet moment with Akka 💕' },

OR click the "+ Add Photo" button directly on the website!
